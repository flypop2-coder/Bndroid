# Original evidence archive

`originals/` preserves the full original-language milestone and planning records, including their prose, commands, hashes, historical limitations, and local artifact paths. These text files retain the source bytes from the September 2026 synchronization; they are not maintained as a second roadmap.

English Markdown pages at the established document paths provide editorial summaries, not line-by-line translations. Follow each page's source link for the complete original record. Historical commands, measurements, and process names describe the original run and must not be interpreted as a current test result or a currently running process.

[TODO.md](../../TODO.md) is the authoritative roadmap. [IMPLEMENTATION_STATUS.md](../../IMPLEMENTATION_STATUS.md) describes current recorded behavior, and [PROJECT_MILESTONES.md](../../PROJECT_MILESTONES.md) indexes the evidence.

Links and relative paths inside verbatim source files retain their original spelling and may refer to the old repository layout. Use the English index for current navigation. Generated artifacts under `target/` remain local and are not published.
