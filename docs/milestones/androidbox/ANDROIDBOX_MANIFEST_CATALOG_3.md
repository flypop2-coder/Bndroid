# AndroidBox Manifest Catalog-3 (ABI 54)

Extends the strict single-launcher Manifest parser to a fixed-capacity component and requested-permission catalog while preserving parent-profile behavior. The real org.bndroid.catalog fixture records six components, two launcher entries, two requested permissions, and four intent filters. Catalog visibility does not itself grant permissions or implement the complete PackageManager.
