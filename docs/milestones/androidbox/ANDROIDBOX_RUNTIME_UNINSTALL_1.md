# AndroidBox Runtime Uninstall-1 (ABI 52)

Adds user-initiated removal of the current bounded APK from Settings > Apps and recovery of the persistent deletion state without an APK source on the next boot. The offline fixture remains within the single-package Resources-1/Envelope-4 compatibility scope and uses the repository's test-only APK-v2 signer.
