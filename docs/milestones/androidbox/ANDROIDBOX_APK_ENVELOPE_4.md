# AndroidBox APK Envelope-4 (ABI 51)

Adds a bounded reader for common APK ZIP envelopes on top of MultiAction-3. Android SDK output can enter the existing compatibility path without repacking every entry as STORED. The original offline gate uses the repository-owned org.bndroid.envelope APK, signed with one APK Signature Scheme v2 signer. Format admission remains strict; this is not an unrestricted ZIP or APK runtime.
