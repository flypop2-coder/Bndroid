# AndroidBox Scene-RPC-2 (ABI 49)

Transfers a complete bounded APK View tree from an independent AndroidApp EL0 worker to the trusted App UI host. The profile uses BNDAPC02 version 2; parent ABI 47/48 BNDAPC01 behavior stays isolated. The recorded offline two-boot gate uses the structurally different org.bndroid.profile fixture and verifies its identity and recovery.
