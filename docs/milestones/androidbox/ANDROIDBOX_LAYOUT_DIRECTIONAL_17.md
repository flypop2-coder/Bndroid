# AndroidBox Layout Directional-17 (ABI 67)

Carries per-side left/top/right/bottom padding and margins from AAPT2 binary XML through the parser, independent AndroidApp worker, fixed process protocol, trusted scene, rasterization, and hit testing. Uniform padding/margin values provide a baseline overridden by explicit sides. These are physical-side properties; start/end and RTL behavior remain future work.
