# AndroidBox String Builder-13 (ABI 63)

Executes the bounded D8 StringBuilder sequence for dynamic text such as Review count: followed by an incremented integer. The Activity retains the counter and TextView reference across callbacks. Builder/string capacity, call shapes, and text projection remain checked within the controlled DEX subset.
