# AndroidBox Layout Weight-15 (ABI 65)

Supports canonical 0dp widths and integer weights 1..8 for Button children of a horizontal LinearLayout. The original profile requires wrap_content height. AAPT2 dimension/float encodings are validated before the worker, scene model, and renderer use the values. Weight semantics remain bounded; vertical weights and general Android layout behavior are outside this milestone.
